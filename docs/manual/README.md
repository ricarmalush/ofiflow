# Manual técnico de OfiFlow

Este manual está escrito para que **cualquier programador junior** entienda de qué va la aplicación, cómo está construida y por qué. Se supone que sabes C# y SQL básicos, pero **no** que conozcas ASP.NET Core, EF Core, MediatR ni los términos de DDD: cada concepto nuevo se explica la primera vez que aparece.

## Cómo leerlo

- Un capítulo por sesión (10-15 minutos). Léelos en orden la primera vez.
- Cada capítulo termina con preguntas para comprobar que lo has entendido. Si no sabes responderlas con tus palabras, vuelve a leer.
- Todo lo que se explica está apoyado en código real del repositorio, con enlaces a los ficheros.
- Este manual **explica cómo funciona** el sistema. El **porqué de cada decisión** está en los [ADR](../adr/), a los que cada capítulo enlaza. No se repite aquí para que no haya dos versiones que se contradigan.
- Cuando algo **todavía no está hecho** se dice claramente. Es parte de entender el proyecto.
